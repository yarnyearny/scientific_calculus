# 面隣接グラフ上の共有経路最適化

## 1. 問題定義

矩形を分割した各面を頂点、辺を共有する面の組を無向辺とする。面 `u` の重心を
`c(u) = (x(u), y(u))` とし、隣接辺の重みを次で定義する。

```text
w(u, v) = |x(u) - x(v)| + |y(u) - y(v)|
```

ゴール面とすべてのスタート面を含む連結部分グラフについて、使用する辺の重みを
一度ずつ加算した値を最小化する。重みが非負なので閉路は除去でき、解はゴールを根
とする木として表現できる。

これは重み付きグラフ上の Steiner tree 問題であり、一般には NP 困難である。本実装
は厳密解ではなく、再現可能な近似・局所探索解を返す。

## 2. アーキテクチャ

依存方向を次の一方向に限定する。

```text
CLI / JSON I/O
      |
    Solver
   /      \
Construction  Order search
   \      /
 Shortest paths / MST
        |
   Domain model
```

### `model.py`

- `FaceGraph`: 面の重心と無向隣接関係を保持し、L1 辺重みを提供する。
- `TreeSolution`: ゴール、スタート、採用辺、総コストを保持する。
- 入力不変条件（未知面、自己辺、非有限座標、非連結な終端）を境界で検査する。

### `paths.py`

- 単一始点 Dijkstra 法
- 現在の木を複数ゴールとする最短路
- 候補部分グラフの Kruskal 最小全域木

アルゴリズム層から距離計算と木の正規化を分離する。

### `construction.py`

二つの初期解生成器を持つ。

1. `sequential_attachment`: 指定順の各スタートを、現在の木への最短路で接続する。
2. `metric_closure_tree`: 終端の距離閉包上で MST を作り、その辺を元グラフの最短路へ
   展開する。

どちらも最後に MST 化と非終端葉の除去を行い、閉路や不要枝を残さない。

### `search.py`

スタート順列を解の遺伝子として扱うランダム再始動付き山登り法を実装する。交換、
挿入、部分列反転を近傍操作とし、`sequential_attachment` で復号して共有辺込みの
総コストを直接評価する。乱数シードを設定でき、同じ入力と設定から同じ結果を得る。

### `solver.py`

以下の候補を同じ評価関数で比較し、最良解を返す。

- 距離閉包 MST
- ゴールから近い順・遠い順の逐次接続
- ランダム再始動と順列局所探索

同コストの場合は辺集合の辞書順で決定し、出力を安定させる。

### `io.py` / `cli.py`

JSON とドメインモデルの変換だけを担当する。アルゴリズムはファイル形式や標準入出力
に依存しない。

## 3. JSON インターフェース

入力例:

```json
{
  "faces": [
    {"id": "g", "centroid": [0, 0]},
    {"id": "a", "centroid": [1, 0]}
  ],
  "adjacencies": [["g", "a"]],
  "goal": "g",
  "starts": ["a"],
  "config": {
    "random_restarts": 16,
    "local_iterations": 200,
    "seed": 0
  }
}
```

出力は総コスト、採用面、ゴールから外向きに並べた親子辺を含む。辺は共有されても
一度だけ出力・加算される。

## 4. テスト戦略

- 単体テスト: L1 重み、入力検査、Dijkstra、MST、不要葉除去
- アルゴリズムテスト: 共有幹を持つ既知グラフ、順序による差、決定性
- 統合テスト: JSON を CLI に渡し、根付き木・コスト・共有辺を検査
- 性質検査: 出力が閉路を持たず、全終端がゴールへ到達し、報告コストが辺の合計と一致

## 5. 意図的な制約

- 面の形状そのものは入力せず、重心と隣接関係を既知とする。
- L1 重心距離はヒューリスティックであり、面内の実際の通過距離ではない。
- 近似解であり最適性証明は返さない。
- 負の辺重みは扱わない（L1 距離なので通常は発生しない）。
